# The save's fields that can name a place of the mod's, and what the district save does with each (Scripts/DistrictSave,
# docs/features/district-save.md). ContractCheck walks every type reachable from GameInstance in the game's assemblies on
# disk and fails, naming the field, while this list is not exactly what it finds: a field a game update or a DLC adds.
#
#   path | what it holds | what the district save does
#
# What it holds: an address, a street's id and its number, a district's id, a position, or an id of someone or a plan
# that leaves with a business; "(obsolete)": the game's binary save leaves it out (a JSON save would write it, and the
# current game never sets it). What the district save does: a kind's code (Scripts/DistrictSave/DistrictSaveRules.cs),
# where "a+b" is a inside a record that leaves (it goes with it) and b inside a record of the game's that stays; "display:"
# a text read only for show, through lookups that are safe when nothing is found; "obsolete".
