# `Scripts/Economy/Estate`

The property business: buying, letting, improving and selling buildings, an estate agency, owning a hotel and hiring out cars, each part with an option of its own.

## Read first

- `EstateDirector.cs`: keeps it going, and every effect and how it is undone.
- `EstateRules.cs`: the rules (game-free).
- `EstateGame.cs`: the game's members it reads and writes.
