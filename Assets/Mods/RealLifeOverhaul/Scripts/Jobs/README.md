# `Scripts/Jobs`

Jobs the player takes themselves, from the Gig Line contact or a help-wanted board, and the six employers whose ranks make them a career (Career*.cs).

## Read first

- `JobDirector.cs`: the one job that is on.
- `JobCatalogue.cs`: every figure (game-free).
- `Job.cs`: the base every job derives from.
- `Kinds/FlyerJob.cs`: the simplest job, to read first.
- `CareerCatalogue.cs`: the employers and ranks (game-free).
