# `Scripts/EndScale`

The end game at scale: data centres, the cloud, broadband and the player's own bank at real costs, crews and upkeep. The ventures it scales keep their own figures; this folder has its feature entry, its option and preset, its two tests and the figures its Guide page prints.

## Read first

- `EndScaleGuide.cs`: the feature entry and the Guide page's figures.
- `EndScaleTests.cs`: the two tests.
