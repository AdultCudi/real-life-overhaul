# `Scripts/Performance`

Fixes for the base game's frame rate, and the measuring that decides them: the F7 probe and the Shift+F7 benchmark.

## Read first

- `PerfDirector.cs`: switches the tweaks as the options ask.
- `PerfTweak.cs`: one optimisation, and how it is put back.
- `PerfTweaks.cs`: the list of tweaks.
