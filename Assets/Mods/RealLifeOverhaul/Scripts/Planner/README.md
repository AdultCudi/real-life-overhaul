# `Scripts/Planner`

The Planner: an app on the game's phone with what the player has to do today and in the next seven days, with reminders and the player's own notes. One class per source in Sources.

## Read first

- `PlannerDirector.cs`: installs the app, asks the sources, sends reminders.
- `PlannerModel.cs`: the clock, entries, clashes (game-free).
- `PlannerRules.cs`: the filter, the way between places, repeats (game-free).
