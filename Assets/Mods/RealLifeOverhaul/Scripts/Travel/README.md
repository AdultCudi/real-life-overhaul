# `Scripts/Travel`

Hotels to stay in and holidays to take, bought at the game's own travel agencies.

## Read first

- `TravelDirector.cs`: the one component, and its watchdog.
- `TravelCatalogue.cs`: every number and name (game-free).
- `TravelState.cs`: the save.
