# `Scripts/Wiring`

Where the features meet: one small file per pairing fills in the bridges each feature offers, each with a default. Nothing here has an Update.

## Read first

- `Wiring.cs`: Connect and Disconnect, the list of pairings.
- `Standing.cs`: the one answer to "has the player a record".
- `Scenes.cs`: one large street scene at a time.
- `LawJustice.cs`: one arrest, one path.
