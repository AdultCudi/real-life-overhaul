# `Scripts/Life`

Random life events (a catalogue, a no-repeat deck and a runner), the sickness mechanic and the shared hospital trip. Also loads and saves ModState.

## Read first

- `LifeEvents.cs`: the component: rolls, sickness, the hospital.
- `LifeEventCatalogue.cs`: the events, in partial files by kind.
- `LifeEventDeck.cs`: dealing without repeats (game-free).
