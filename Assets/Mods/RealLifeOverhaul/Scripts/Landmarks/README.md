# `Scripts/Landmarks`

Uptown's landmarks: Summit Tower, Uptown Galleria and Crest Field, the city's megaprojects on blocks of the new district's first block. Each is held from the first load, announced in the City Ledger, tendered in the construction game or built by the city's own works, set out as a site of the city's construction programme, handed to the district and opened with a ceremony; then it lifts the traffic of the lots round it, and the stadium has its home matches.

## Read first

- `LandmarkRules.cs`: every rule, game-free (checked by EconomyCheck's `LandmarksChecks.cs`).
- `LandmarksDirector.cs`, then `LandmarksDirector.Works.cs`: the state, its timing and each landmark's life.
- `LandmarksGame.cs`: the only file that touches the game's scene.
