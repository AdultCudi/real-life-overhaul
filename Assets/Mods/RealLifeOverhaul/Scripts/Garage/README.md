# `Scripts/Garage`

The custom shop for cars, and bicycles and motorbikes made from the game's scooters.

## Read first

- `GarageDirector.cs`: the one component that ticks.
- `GarageCatalogue.cs`: paint chart, parts and every price (game-free).
- `GarageCar.cs`: one car wearing its build.
- `TwoWheelers.cs`: bicycles and motorbikes.
