# `Scripts/Meta`

The mod about itself: the feature registry, the in-game Guide and welcome notice, realism presets, the options page in sections, the Settings app, the save tools and the bug report.

## Read first

- `Features.cs`: the registry.
- `FeatureList.cs`: every feature, one statement each.
- `OptionsLayout.cs`: the options page in order.
- `SaveTools.cs`: preparing a save for removing the mod.
