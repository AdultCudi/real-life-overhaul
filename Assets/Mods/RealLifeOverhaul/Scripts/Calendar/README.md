# `Scripts/Calendar`

The Calendar: an app on the game's phone with the month the player is in, as the year they chose divides it, the days money moves on, their own time and what is on in the city.

## Read first

- `CalendarDirector.cs`: puts the app on the phone, asks the sources for a month.
- `MonthViewRules.cs`: the grid of weeks, repeats, birthdays and the order (game-free).
- `CalendarGame.cs`: the only file that touches the game.
