# `Scripts/Permadeath`

An ending the player chooses: off unless switched on, kept per save; a death after a warning, the obituary, the save ended.

## Read first

- `PermadeathRules.cs`: when a danger may end a life (game-free).
- `PermadeathDirector.cs`: the one component.
- `Mortality.cs`: the one door the dangerous features call.
