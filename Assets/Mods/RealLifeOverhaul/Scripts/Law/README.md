# `Scripts/Law`

Police precincts, being arrested and held, the criminal record and reputation.

## Read first

- `LawBook.cs`: the offence table and its sums (game-free).
- `LawDirector.cs`: the one tick a second.
- `Custody.cs`: one arrest, from the street to the cell.
- `Record.cs`: the record and both reputations.
