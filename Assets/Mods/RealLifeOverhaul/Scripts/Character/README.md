# `Scripts/Character`

Character quality: the detailed player in the city, a scalp under its hair, the hair finish, character-screen lighting, and the mod's garments in the game's own clothes grids.

## Read first

- `CharacterQuality.cs`: the entry points (city, character creation).
- `CharacterCatalogue.cs`: the new looks on offer, and whose picks they are.
- `ModLooks.cs`: the scalp underlay and any picked look on the characters that show the player.
