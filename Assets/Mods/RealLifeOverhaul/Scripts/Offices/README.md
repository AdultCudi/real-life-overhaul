# `Scripts/Offices`

Empty shops as offices: some of the city's empty shops are offices while the mod runs, so a district with offices keeps at least two to let after the mod's own buildings have taken theirs.

## Read first

- `Conversions.cs`: the conversion, and its option.
- `ConversionRules.cs`: which shops and how many (game-free).
- `ConversionGame.cs`: everything it reads from or does to the game.
