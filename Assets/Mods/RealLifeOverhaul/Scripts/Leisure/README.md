# `Scripts/Leisure`

Things to do for fun at real places, the mod's clothes as something bought, night life, the sound bed and photo mode.

## Read first

- `LeisureDirector.cs`: the one activity that is on.
- `LeisureActivity.cs`: the base every activity derives from.
- `LeisureApi.cs`: the door for the rest of the mod.
