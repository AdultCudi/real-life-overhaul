# `Scripts/Faults`

Real faults in the city worth reporting: street lamps gone dark, potholes, litter, crime hot spots and unsafe places, rolled as the game runs, kept in the save, shown in the street and reported on Flare.

## Read first

- `FaultDirector.cs`: the hour, the reports, the street.
- `FaultRules.cs`: the rules (game-free).
- `FaultStore.cs`: the save.
- `FaultBridges.cs`: what it asks of the others.
