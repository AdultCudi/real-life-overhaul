# `Scripts/Fame`

Standing: a city that reacts to the player's success. Wealth, recognition (how many people know them) and reputation with customers, workers, neighbourhoods and for integrity.

## Read first

- `FameDirector.cs`: keeps it going: no Update, the work on the game's events.
- `FameRules.cs`: the daily round (game-free).
- `FameGame.cs`: what it reads of the game.
