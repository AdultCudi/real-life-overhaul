# `Scripts/World`

Entering buildings and vehicles with a key, visual grading, and every feature's places on the city map (MapLinks).

## Read first

- `NearbyInteraction.cs`: the interact key at a door or a vehicle.
- `MapLinks.cs`: every feature's places on the city map.
- `VisualEnhancer.cs`: visual grading.
