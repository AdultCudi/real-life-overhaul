# `Scripts/FitOut`

The fit-out of the mod's own buildings (the tech headquarters, a police station's back rooms, a data centre's floor, the courthouse) with the game's own furniture, by a design for each kind of place.

## Read first

- `FitOutDirector.cs`: which buildings, and when.
- `FitDesigns.cs`: the designs, by kind of place.
- `FitPlanner.cs`: the room measured and planned.
- `FitRules.cs`: the rules (game-free).
