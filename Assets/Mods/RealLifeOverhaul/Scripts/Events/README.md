# `Scripts/Events`

City events: fires and the fire service, weather that matters, and street events, one large scene at a time.

## Read first

- `EventDirector.cs`: the one scene that is on.
- `Weather.cs`: the factors other features read.
- `EventCalendar.cs`: what is on which day.
