# `Scripts/Business`

Pressure on the businesses the player runs: rivals, a racket, inspections, staff, suppliers, customers, audits and opportunities, each with choices on the Business desk contact.

## Read first

- `BusinessCatalogue.cs`: every kind of issue and every number that bounds it (game-free).
- `BusinessDirector.cs`: the hourly clock, the one roll a morning, the off switch that puts everything back.
- `BusinessGame.cs`: the only code that reads or changes the game's business fields.
