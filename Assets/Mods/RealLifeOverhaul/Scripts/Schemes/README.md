# `Scripts/Schemes`

Schemes and inquiries: white collar schemes that sit where the honest action sits (an invented insurance claim, an invented expense, dressed books, a club that does not exist, cash through a till, money to people with power), each leaving a trail that inquiries follow into the mod's own courts, with the rival tycoons doing the same by the same rules.

## Read first

- `SchemeDirector.cs`: the state, the day and the save; its parts carry out a day's events, a press, the people and the pages.
- `SchemeCatalogue.cs`: every figure (game-free).
- `SchemeRules.cs` and its parts: the trail, the money, the people, the day and the rivals (game-free).
- `SchemePages.cs`: each page as plain data, every answer with its press (game-free).
- `SchemeGame.cs`: the only file that touches the game.
