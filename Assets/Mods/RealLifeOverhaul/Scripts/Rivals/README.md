# `Scripts/Rivals`

The rival tycoons: two or three named fortunes, each with a holding company on the stock market, who grow with the city and with the player and move against them in the late game. They rest in a Going Public session.

## Read first

- `RivalDirector.cs`: keeps it going; the rivals' day once.
- `RivalRules.cs`: the rules' round (game-free).
- `RivalBridges.cs`: every move, through the feature that owns what it touches.
