# `Scripts/Ragdoll`

People hit by cars: ragdoll physics, pedestrian collisions, the player knocked down.

## Read first

- `RagdollSystem.cs`: the six ragdolls there are, and the only per-frame work.
- `PedestrianIncidents.cs`: what a hit does by speed.
- `PlayerKnockdown.cs`: the player on foot hit by traffic.
