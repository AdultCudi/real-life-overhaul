# `Scripts/Crime`

Crime near the player, by the player and against the player: street crimes with a cast and an arrest, crimes rolled off screen, and the police noticing the player's own offences.

## Read first

- `CrimeCatalogue.cs`: every crime, its odds and lines; fines and odds in CrimeLaw.
- `CrimeDirector.cs`: one scene at a time.
- `CrimeScene.cs`: the base every scene shares.
- `PoliceAttention.cs`: the player's own offences.
