# `Scripts/Districts`

The district view on the city map: ten layers in its filter list tint each district, with a key, a card and the districts in order.

## Read first

- `DistrictRules.cs`: the layers, bands and colours (game-free).
- `DistrictView.cs`: the one component.
- `DistrictBridges.cs`: one reading per district from the others.
