# `Scripts/Justice`

Courts and prison: cases, bail, lawyers, the courthouse, hearings, sentences, the Legal file.

## Read first

- `JusticeLaw.cs`: every charge, cap, fee and formula (game-free).
- `JusticeDirector.cs`: the clock and the switchboard.
- `JusticeBridges.cs`: the door for the rest of the mod.
